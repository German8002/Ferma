Блуждающие хищники 
Монстры (M) больше не стоят на месте как вкопанные! В фазу Update (после каждого шага или действия игрока) каждый живой монстр на карте выбирает случайное направление (вверх, вниз, влево, вправо) и, если клетка пуста (.), перемещается на неё. Если монстр сам шагает на клетку игрока — он наносит первый удар!
